## Best work

- **[ScamShield AI](https://github.com/sahithsundarw/Scamshield-AI)**: an agentic
  honeypot that engages scammers and extracts UPI IDs, bank accounts and phishing
  links. FastAPI, GPT-4o, MongoDB, React. 229 offline tests, live demo.
- **[Sentinel](https://github.com/sahithsundarw/sentinel)**: an RL environment for
  training content-safety moderators against an adaptive adversary. GRPO/REINFORCE
  on Llama-3.1-8B plus a Q-learning baseline, with reported results and caveats.
- **[Image restoration for semiconductor inspection](https://github.com/sahithsundarw/bunker_backer)**:
  a 1.39M-parameter NAFSR network, 29.59 dB PSNR on held-out data, beats a U-Net baseline.
  README documents failed experiments.
- **[Atlas](https://github.com/sahithsundarw/Atlas)**: a LangGraph travel agent with
  RAG, parallel tool calls, guardrails and a 25-case eval harness.
